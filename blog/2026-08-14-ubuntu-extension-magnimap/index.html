GNOME Extension: Magnimap

Magnimap is a GNOME extension that provides better features for the magnifier tool in GNOME. It allows users to customize the magnification level, it has a mini-map that shows the entire screen in a corner, and most importantly, it has a dead zone feature that allows users to define areas of the screen that should not respond to mouse movements. This is a generalization of keeping the mouse in the center of the screen or letting the mouse move the screen when touching the edges.
